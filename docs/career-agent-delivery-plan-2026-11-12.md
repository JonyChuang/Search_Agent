## 12 日交付范围

1. 从真实经历与目标 JD 出发，Agent 生成并保存一份训练计划。
2. 用户可查阅面经、刷题、查看反馈并复习错题，能够完成一轮岗位面试问答。
3. 针对同一岗位生成有事实依据的简历草稿并保存版本，支持打印为 PDF。
4. 网申助手保存岗位、简历版本和表单答案草稿。用户在招聘网站人工提交后，通过投递看板更新进展。
5. 从前端能查看任务状态和结果。重复创建任务、用户隔离与失败重试有实际验证。

工程亮点优先交付 Java 与 Agent 的业务边界、工具权限校验、任务持久化、进度查询及业务去重。上下文优先按任务加载当前 JD、经历和练习记录。完整压缩与长短期记忆依照工程设计另行实现和测量。

完整版排在 v1 之后。包括跨站自动网申与回执、在线编程和 SQL 沙箱、用户安装 Skill 包、完整上下文压缩、长期记忆、分布式并发调度和 RL。v1 复用内置 Skill 与现有模型设置。实际实现范围以验收记录为准。
